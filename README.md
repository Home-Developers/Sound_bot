# 🎵 Discord Sound Bot (Spotify, SoundCloud, Deezer)

Повнофункціональний музичний бот для **Discord**, який відтворює музику у голосових каналах (Voice Chat) за посиланнями з:
- 🟢 **Spotify** (окремі треки, альбоми, плейлисти)
- 🟠 **SoundCloud** (треки, сети, плейлисти)
- 🟣 **Deezer** (треки, альбоми, плейлисти)
- 🔴 **YouTube / прямі посилання** та звичайний текстовий пошук

Бот підтримує сучасні **слеш-команди (`/`)**, звичайні текстові команди з префіксом (наприклад, `!play`), а також **інтерактивні кнопки керування** під повідомленням відтворення.

---

## 🚀 Швидкий старт

### 1. Налаштування токена бота
1. Перейдіть на [Discord Developer Portal](https://discord.com/developers/applications) та створіть новий додаток (Application).
2. У вкладці **Bot** натисніть **Reset Token** та скопіюйте отриманий токен.
3. Увімкніть **Privileged Gateway Intents**:
   - ✅ **Message Content Intent**
4. У вкладці **OAuth2 -> URL Generator**:
   - Оберіть Scopes: `bot`, `applications.commands`
   - Оберіть Bot Permissions: `Connect`, `Speak`, `Send Messages`, `Embed Links`, `Read Message History`, `Use Voice Activity`
   - Скопіюйте посилання та запросіть бота на свій сервер.

### 2. Створення файлу `.env`
Скопіюйте `.env.example` у файл `.env`:
```env
# Токен бота
DISCORD_TOKEN=ваш_токен_discord_тут

# Префікс для текстових команд
COMMAND_PREFIX=!

# [Опціонально] Ключі Spotify API (https://developer.spotify.com/dashboard)
# Якщо залишити пустими, бот працюватиме через вбудований розумний парсер!
SPOTIFY_CLIENT_ID=
SPOTIFY_CLIENT_SECRET=
```

### 3. Запуск бота
- **Спосіб 1 (найпростіший на Windows):** двічі клікніть по файлу **`run.bat`**.
- **Спосіб 2 (через термінал):**
  ```powershell
  # Активація віртуального оточення
  .\.venv\Scripts\activate

  # Запуск бота
  python main.py
  ```

## 🎶 Доступні команди

Всі команди доступні як через **слеш (`/`)**, так і через префікс (наприклад, `!play`):

| Команда | Опис |
| :--- | :--- |
| `/play <посилання або назва>` | Грати музику з Spotify, SoundCloud, Deezer або за пошуком |
| `/pause` | Призупинити відтворення |
| `/resume` | Продовжити відтворення |
| `/skip` (або `/next`) | Пропустити поточний трек |
| `/stop` (або `/leave`) | Зупинити музику, очистити чергу та вийти з голосового каналу |
| `/queue` | Показати список треків у черзі |
| `/nowplaying` | Показати картку поточного треку з кнопками |
| `/loop [off/track/queue]` | Перемкнути режим повтору (вимкнено / трек / вся черга) |
| `/shuffle` | Перемішати чергу у випадковому порядку |
| `/volume <1-200>` | Налаштувати гучність звучання |
| `/clear` | Очистити чергу треків |

## 🎛️ Інтерактивні кнопки плеєра

Під час відтворення бот відправляє гарну картку з інформацією про пісню та кнопками:
- ⏯️ **Пауза / Продовжити** — перемикання паузи
- ⏭️ **Пропустити** — перехід до наступного треку
- 🔁 **Повтор** — циклічне перемикання повтору поточного треку або всієї черги
- 📜 **Черга** — швидкий перегляд черги для користувача
- ⏹️ **Зупинити** — завершення відтворення

## 🛠️ Як це працює під капотом

1. **SoundCloud**: Пряме витягування потоку через `yt-dlp` у найвищій якості.
2. **Deezer**: Використовує офіційний публічний REST API Deezer (`api.deezer.com`) для миттєвого отримання метаданих треків/альбомів/плейлистів, після чого бот стрімить аудіопотік.
3. **Spotify**: Якщо вказані ключі Spotify API, використовується офіційна бібліотека `spotipy`. Якщо ключів немає — працює швидкий парсер Spotify Embed та oEmbed, що дозволяє слухати треки та плейлисти без реєстрації в Spotify Developer!
4. **FFmpeg**: Декодує аудіопотоки та передає їх у Discord Voice Gateway за допомогою кодека Opus.
